# FROSTMOURNE

Infrastructure and future Windows x86 modules targeting **World of Warcraft 3.3.5a, build 12340**.

Start with [AI_START_HERE.md](AI_START_HERE.md). `main` is the accepted stable branch; `work` is development.

The repository currently contains no game module or active runtime binary. CI verifies repository/runtime manifests and proves the Windows hosted runner can compile a CI-only x86 PE smoke executable.
